# c001apk iOS 精简版

基于 [TG-Twilight/c001apk](https://github.com/TG-Twilight/c001apk) 的 `1.5.2-release`，固定源码提交 `c034b98a536423fb23b35feda39dc63bf8043bb8`。本仓库保存定制补丁和可重复的 iPhone 云端打包流程，使用上游公开实现。

## 定制内容

- 第六版：普通评论和用户名直接绘制文字，减少首次显示时的 HTML 解析与组件创建；HTML、实体、表情标记、特殊空白和超长文本继续使用原渲染流程。20 条实际普通评论对照测试中，HTML 组件从 40 个降为 0 个，卡片尺寸一致；这不是对真机帧率的测量。
- 第六版：新增文字样式、换行、缩放、选择、链接点击、回复交互、表情及原图参数回归；iOS 原生触摸示例也使用本次普通文字路径。保留原图 URL、图片缩放/切换/关闭和帖子返回手势。
- 第五版：内容过滤服务关闭或不存在时，不再为卡片解析正文和文章 JSON，保留独立的个人作者/话题黑名单。
- 第五版：明确的普通纯文本跳过完整 Markdown 解析；显式 Markdown、HTML、实体和潜在语法仍走原有流程。保留第四版的性能记录、图片放大动画、手势和画质。
- 第四版：设置增加可关闭的浏览性能记录，最多采集5分钟，仅在本机内存中保留有界事件、帧耗时与慢帧。记录分页等待、过滤/发布、图片准备与固定页面分类；不记录账号、正文、图片URL或请求参数，不自动上传，用户可主动导出或复制。
- 第四版：分页复用未变化内容的解析输入，每次仍执行当前过滤规则与原有去重；500条历史追加20条只新增20次解析。缓存有数量及文本大小上限，刷新、内容变更或页面关闭时清理/失效；服务器游标与验证流程不变。
- 第四版：图片页以居中放大淡入方式打开，底层列表保持原位；保留边缘跟手返回、下滑关闭、左右切图、双指缩放与减少动态效果。图片记录共用现有缓存与解码尺寸，不降低原图清晰度。
- 第三版：图片详情页增加单指下滑关闭、短滑回弹、反向甩回取消；仅适屏比例下生效，保留左缘返回、左右切图、双指缩放和放大后平移。第二指（含顶部区域）、菜单和取消事件均中止下滑退出。
- 第三版：单列信息流使用原生懒加载列表，缩略图按显示尺寸及屏幕像素密度限制内存解码；不改变图片地址、图库原图、分页数据或登录流程。
- 第二版：iOS 正文跟手右滑返回与取消、横向子控件手势优先、编辑与弹窗保护、多指操作保护，以及减少动态效果时的返回行为。
- 修正底部主页/关注/我的选中背景、图标、文字在胶囊中的垂直居中；iPhone 底部安全区保留在胶囊外。
- iOS 搜索历史竖拖收起键盘，保留未提交输入；长历史列表约束在键盘上方可用区域。
- 帖子、主页当前分类、关注和我的支持轻点系统状态栏回顶部；使用页面原有滚动控制器，不触发刷新，隐藏分类的浏览位置保留。
- 以 `C001APK_LITE=true` 构建：自动版本检查和弹窗关闭，旧设置不能重新启用；手动检查原版更新保留。
- 新安装默认关闭项目公告自动检查，仍可手动查看或主动开启；正文、重要公告、未读状态保留。
- 上游 iOS 已不含安卓应用管理更新入口、APP 更新数字角标和官方个人页 FAQ 横栏；未发现广告 SDK。保留已有内容类型白名单，不增加猜测性广告规则。
- 登录、验证码、请求与响应处理、分页游标、普通消息提醒均保持上游实现。
- 应用名称为 `c001apk 精简版`，独立标识 `com.randyliu2020.c001apk.lite`，最低系统目标 iOS 15.0。

这是一款独立的第三方客户端，不是酷安 Android v10 的二进制转换，界面和媒体体验与官方酷安及上游私有扩展构建不同。

## 云端构建

推送构建文件至 `main` 或手动运行 Actions。流程检出上述固定公开源码并应用 `customization.patch`，使用 Flutter 3.47.7，先执行静态分析、上游离线测试和精简模式测试，再在 `xcode-27` 标准 runner 编译 iPhone arm64 release。第六版构建号为日期后加 `.6`。

模拟器步骤使用固定的离线示例页面，复用真实帖子路由、底部导航和真实图片详情页，实际运行 iOS 27 触摸测试。内存图片覆盖下滑关闭、左右切图、双指放大后拖动不关闭和边缘返回。测试入口仅用于 simulator，正式 IPA 明确以 `lib/main.dart` 构建，不包含该示例入口。明暗主题、放大字体的布局预览与模拟器截图作为独立附件保存。最终通过情况以本次 Actions 记录为准。

不上传或使用 Apple 签名证书、描述文件、酷安账号资料或上游私有扩展密钥。产物为 `Payload/Runner.app` 结构的未签名 IPA，以及 SHA256 和架构校验报告；由用户在全能签中自行签名安装。Actions 附件保留 14 天。全部检查通过后，流程核验同次构建的源码、附件与 IPA 哈希，再发布到公开 Releases，提供 iPhone 可直接下载的 IPA 链接。

本机复现（需要 macOS/Xcode 和上述 Flutter 版本）：检出固定上游、应用补丁，在 `apps/flutter` 安装锁定依赖，再执行 `flutter build ios --release --no-codesign --dart-define=C001APK_LITE=true`；完整步骤见 workflow。

编译与离线测试不能证明 iPhone 实际登录、验证码交互或长期服务端兼容性；这些需要真机验收。没有提供修改检测或账号限制解除保证。

本机使用与云端一致的 Flutter 3.47.7 / Dart 3.13.5，第六版新增14项测试；完整离线回归680项通过、4项跳过，精简模式81项通过。普通文字对照覆盖多语言、明暗主题、RTL、线性与非线性缩放，文字和卡片尺寸保持一致。静态分析无 error/warning。云端还会复跑 Linux 回归并执行7项 iOS 27 模拟器触摸测试；最终通过情况以对应 Actions 记录及交付校验报告为准。

安装第六版后，在“设置 → 浏览性能记录”开启采集，返回刷帖30至60秒，遇到卡顿后回到记录页停止并导出。可分别采集首次浏览和回刷同一段内容。8.33/16.67毫秒阈值不是实际FPS或掉帧计数；图片准备包含等待，长耗时不等于滚动阻塞。记录用于真机诊断，不能代替实际测量结论。

ProMotion 配置原先已经启用；性能优化尚未经用户 iPhone 16 Pro Max 真机测量，不能视为稳定 120 帧的证明。复查命令：`flutter analyze --no-pub --no-fatal-infos` 和 `flutter test --no-pub --dart-define=C001APK_LITE=true test/lite`。
